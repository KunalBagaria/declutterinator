Declutter-inator

A free, open-source way to clean up your Mac. It finds the gigabytes hiding in caches, build folders and old downloads, shows you every one, and removes only what you pick.

curl -fsSL https://declutter.kunalbagaria.com/install | sh

Paste it into Terminal. It installs one program to ~/.local/bin and runs on macOS 11 or later, on Apple silicon or Intel. You can read the script before you run it, or use Homebrew instead: brew install kunalbagaria/tap/declutterinator.

What it looks for

Everything it finds goes into one of three groups, so you always know what you’re agreeing to. If you’d rather free up disk space by hand, the guide to cleaning up your Mac covers each of these places and the commands to clear them.

Safe to zap
Things that grow back on their own: app caches, logs, the Trash, Xcode DerivedData, and the download caches of npm, Yarn, pnpm, Bun, pip, uv, Cargo, Gradle, Go, CocoaPods and Homebrew. These start out selected.
Probably fine
Things that cost a re-download or a rebuild: node_modules, target, .venv, Pods and .next folders in projects you haven’t touched for a month, Docker images, old installers, and zip files sitting next to the folder you unzipped them into.
Your call
Your own files: old downloads, very large files, apps you haven’t opened in six months, iPhone backups and Xcode archives. Nothing here is ever selected for you, and whatever you pick goes to the Trash, not away for good.

What is claimed

A machine for reclaiming disk space, wherein:

  1. nothing is removed until you confirm, and clean --dry-run lists every path first;
  2. your own files go to the Trash, and only caches and build output are deleted outright;
  3. every path is checked again right before removal: it has to be inside your home folder, and .ssh, Keychains, iCloud Drive, Mail and Messages are off limits;
  4. it never follows a symlink and never wanders onto another disk;
  5. a node_modules folder only counts if a package.json sits next to it, and a target folder only if a Cargo.toml does;
  6. sizes are what files actually occupy, so space shared through APFS clones or hard links is never promised twice;
  7. the self-destruct button is not connected to anything.

Using it

declutterinator
Scan, read the report, then choose what to remove.
declutterinator clean --dry-run
List every path that would be removed. Changes nothing.
declutterinator clean --safe --yes
Clear everything in the safe group without asking. Good for a monthly cron job.
declutterinator big ~/Library -d 2
See what’s taking up space, folder by folder.
declutterinator dupes ~/Pictures
Find duplicate files, and tell real copies from APFS clones.
declutterinator categories
List everything it knows how to find.

Run the install line again to upgrade, or brew upgrade declutterinator if you used Homebrew. To uninstall, delete ~/.local/bin/declutterinator (or run brew uninstall declutterinator).
